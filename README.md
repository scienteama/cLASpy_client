## Description

**cLASpy_Client** is the user interface (frontend) for the **cLASpy_T** project, built with  
[Vue.js](https://vuejs.org) and the [Quasar Framework](https://quasar.dev).

It serves as the main access point to the modular **cLASpy_T** system, allowing users to:

- **Train machine learning models** for remote sensing data classification with **cLASpy_ML** plugin.
- **Make predictions** to classify remote sensing data with **cLASpy_ML** plugin.
- **Compute geometric features** at several radius with **cLASpy_features** plugin (*in progress*).

---

## Installation & Launch

```bash
# Clone the repository
git clone https://github.com/your-org/CLASpy_Client.git
cd CLASpy_Client

# Install dependencies
npm install

# Start the development server
quasar dev
```
